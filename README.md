# Эмулятор оболочки ОС - вариант 20

Практическая работа по конфигурационному управлению, вариант 20.

## Возможности

- графическое окно в стиле Terminal macOS;
- защищённая от ввода область истории команд;
- приглашение `vfs:~$` перед каждой командой;
- отдельное поле для ввода команды внизу окна;
- отображение вводимой команды в строке приглашения в реальном времени;
- разбор введённой строки на команду и аргументы по пробелам;
- команды-заглушки `ls` и `cd`;
- команда `exit` для завершения работы;
- сообщения об ошибках для пустого ввода, неизвестной команды и неверного
  вызова `exit`.
- параметры запуска для пути к VFS, JSON-журналу и стартовому скрипту;
- журнал вызовов команд в формате JSON;
- последовательное выполнение команд из стартового скрипта.

На первом этапе виртуальная файловая система ещё не подключена. Имя VFS
`demo-vfs` отображается в заголовке окна.

## Запуск

Нужен Python 3 с библиотекой Tkinter. В macOS и большинстве дистрибутивов
Python она входит в стандартную поставку.

```bash
./run.sh
```

Либо:

```bash
python3 -m src.main
```

### Параметры запуска

| Параметр | Назначение |
| --- | --- |
| `--vfs-path <путь>` | Путь к исходной директории VFS. |
| `--log-path <путь>` | Путь к JSON-файлу с журналом команд. |
| `--script-path <путь>` | Путь к текстовому стартовому скрипту. |

Например:

```bash
./run.sh \
  --vfs-path examples/vfs \
  --log-path logs/commands.json \
  --script-path scripts/startup_basic.txt
```

При запуске все параметры выводятся в консоль PyCharm или терминала. Если
параметр лога указан, каждое событие содержит имя команды, аргументы, имя
пользователя, дату и время, а также признак успешности выполнения.

### Стартовый скрипт

Скрипт — это UTF-8 текстовый файл с одной командой на строку. Пустые строки
пропускаются. Ошибочная команда отображает ошибку, но не останавливает
выполнение следующих строк.

Готовые примеры запуска:

```bash
./scripts/run_basic_demo.sh
./scripts/run_error_demo.sh
```

Оба скрипта проверяют все три параметра запуска. Второй дополнительно
демонстрирует обработку ошибочных строк.

## Команды

| Команда | Описание на первом этапе |
| --- | --- |
| `ls [аргументы]` | Выводит имя команды и переданные аргументы. |
| `cd [аргументы]` | Выводит имя команды и переданные аргументы. |
| `exit` | Закрывает приложение. Аргументы не принимает. |
